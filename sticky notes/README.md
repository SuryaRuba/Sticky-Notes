# Sticky Notes Desktop App

A simple desktop sticky notes application built with Python and Tkinter.

## Features
- Create new notes
- Drag notes around the screen
- Change note color
- Delete notes
- Save notes to a JSON file for persistence

## Run on Windows
From this folder, double-click `run_sticky_notes.bat`, or run:

```bat
python sticky_notes.py
```

## Tests
Run the test suite with:

```bat
python -m unittest discover -s tests -v
```
